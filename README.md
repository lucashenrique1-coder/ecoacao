# EcoAção

Landing page educativa sobre sustentabilidade no dia a dia,
desenvolvida como trabalho acadêmico do curso de ADS do Senac.

## Objetivo

Incentivar pequenas atitudes sustentáveis, como economizar água,
separar resíduos e consumir de forma consciente.

O projeto aborda o tema Agenda 2030 proposto na atividade.

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5.3.8
- JavaScript

## Recursos

- Menu com navegação entre seções da mesma página.
- Cards com dicas de sustentabilidade.
- Layout responsivo para computadores e celulares.
- Formulário demonstrativo com nome e e-mail.
- Validação de campos obrigatórios e formato de e-mail.
- Mensagem personalizada usando JavaScript.

## Componentes do Bootstrap

- Navbar.
- Cards.
- Formulário e botões.

## Organização dos arquivos

- index.html: estrutura e conteúdo.
- style.css: personalização visual.
- script.js: comportamento do formulário.
- README.md: documentação do projeto.

## Como executar

Abra o arquivo index.html no navegador ou utilize o Live Server
no VS Code.

É necessário acesso à internet para carregar o Bootstrap via CDN.

## Observação sobre o cadastro

O formulário é demonstrativo. Nenhum dado é enviado ou armazenado.
